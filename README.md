# Toko Sepatu Adidas Suede Series - Tugas Praktikum PWEB

Website katalog dan toko online sederhana untuk produk sepatu Adidas Suede Series (Gazelle, Campus, Spezial, dan City Series).


## 🔗 Link Live Deployment
- **Vercel:** https://tugas-praktikum-24sept.vercel.app

## 🛠️ Fitur Utama & Penerapan DOM JavaScript
1. **Render Produk Dinamis:** Menampilkan katalog sepatu menggunakan DOM Manipulation secara otomatis dari data JavaScript.
2. **Filter & Pencarian:** Fitur penyaringan kategori (Gazelle, Campus, Spezial, City Series) dan pencarian nama sepatu secara *real-time*.
3. **Mode Gelap / Terang (Dark Mode):** Pengubah skema warna antarmuka berbasis CSS Variables dan Event Listener pada tombol switcher.
4. **Keranjang Belanja Modal:** Fitur tambah produk ke keranjang beserta kalkulasi total harga otomatis.
5. **Responsif:** Tampilan yang menyesuaikan untuk perangkat mobile, tablet, dan desktop.

---

## 💻 Teknologi yang Digunakan
- **HTML5** (Struktur elemen website)
- **Plain CSS3** (Flexbox, Grid, & CSS Variables)
- **Vanilla JavaScript** (DOM Manipulation & Event Handling)
